# 📒 دفتر کار | Daftar

**دفتر کار** یک نرم‌افزار سبک، مدرن و فارسی برای مدیریت یکپارچه کسب‌وکار شخصی است که برای فریلنسرها، طراحان، برنامه‌نویسان، متخصصان خدماتی و صاحبان کسب‌وکارهای کوچک طراحی شده است.

دفتر کار تلاش می‌کند تمام اطلاعات روزمره یک کسب‌وکار را در یک محیط واحد جمع کند؛ از درآمد و هزینه و بدهی گرفته تا مشتری، پروژه، تسک، تبلیغات، پیگیری مشتری، فعالیت‌های رشد، ایده‌ها و ابزارهای هوش مصنوعی.

> 🎯 هدف اصلی: بدانید **الان چه مقدار پول دارید، چه کسانی به شما بدهکارند، به چه کسانی بدهکارید، روی چه پروژه‌هایی کار می‌کنید و امروز چه کارهایی باید انجام دهید.**

---

## ✨ چرا دفتر کار؟

در بسیاری از کسب‌وکارهای کوچک، اطلاعات در چند جای مختلف پخش شده‌اند:

- حسابداری در Excel
- مشتری‌ها در تلفن
- پروژه‌ها در پیام‌رسان
- کارها در یادداشت موبایل
- ایده‌ها در دفترچه
- تبلیغات در ذهن
- ابزارهای هوش مصنوعی در Bookmark مرورگر

**دفتر کار** این اطلاعات را در یک سیستم واحد قرار می‌دهد.

این نرم‌افزار با رویکرد **Local-First** طراحی شده است؛ یعنی اطلاعات اصلی شما به‌صورت محلی روی سیستم ذخیره می‌شوند و برای استفاده عادی از نرم‌افزار به حساب کاربری یا سرور ابری نیاز ندارید.

# 📈 رشد کسب‌وکار

دفتر کار فقط برای ثبت اطلاعات گذشته نیست؛ برای مدیریت رشد آینده کسب‌وکار نیز طراحی شده است.

می‌توانید فعالیت‌های رشد تعریف کنید، مانند:

- نردبان کردن آگهی دیوار
- انتشار پست اینستاگرام
- انتشار استوری
- تماس با مشتری قدیمی
- بررسی رقبا
- بررسی SEO
- تولید محتوا
- پیگیری Leadها

فعالیت‌ها می‌توانند تکرارشونده باشند.

مثلاً:

> انتشار پست اینستاگرام → هر ۳ روز

یا:

> بررسی رقبا → هر هفته

پس از انجام هر فعالیت، نوبت بعدی به‌صورت خودکار برنامه‌ریزی می‌شود.

# 🔐 حریم خصوصی

دفتر کار با رویکرد **Local-First** طراحی شده است.

در استفاده عادی:

- نیازی به ثبت‌نام نیست.
- نیازی به Login نیست.
- نیازی به حساب کاربری نیست.
- داده‌های اصلی روی سیستم شما ذخیره می‌شوند.
- استفاده از نرم‌افزار به Cloud Server وابسته نیست.

این ویژگی باعث می‌شود اطلاعات شخصی و کاری شما کنترل‌شده‌تر باقی بمانند.

> ⚠️ با این حال، فایل‌های Backup خود را مانند هر فایل مالی یا شخصی مهم دیگری ایمن نگه دارید.
